# K-ART FACTORY Software Development

## K-ART FACTORY ソフトウェア開発記録

K-ART FACTORYが企画・開発したソフトウェアの記録を公開する公式リポジトリです。

私たちは、ITとAIを活用し、お客様の困りごとを解決するためのソフトウェア開発に取り組んでいます。

## 開発ソフトウェア

### 1. K-ART Graphic Studio

ブラウザ上で画像編集やグラフィック制作ができるソフトウェアです。

主な機能：
- レイヤー編集・マスク
- テキスト入力・自由変形
- ブラシ・ペン・自動選択
- 色調補正・画像効果
- プロジェクト保存・再編集
- 画像・PDF書き出し

### 2. K-ART Vector Studio

ブラウザ上でベクターグラフィックを制作・編集できるソフトウェアです。

主な機能：
- 図形・パス編集
- ペンツール・テキスト編集
- 塗り・線・グラデーション
- オブジェクトの変形・整列
- 印刷向けデータ制作
- PNG・PDF書き出し
